# 🎨 Pixel Playground - Drawing App

A browser-based pixel drawing playground built with React.

## Features

- Draw on a pixel grid with your mouse
- Choose colors and brush size
- Clear the canvas
- Responsive and interactive UI

## Getting Started

### Prerequisites

- Node.js (v14+ recommended)
- Yarn or npm

### Installation

1. Install dependencies:
   ```
   yarn install
   ```
   or
   ```
   npm install
   ```

2. Start the development server:
   ```
   yarn start
   ```
   or
   ```
   npm start
   ```

3. Open your browser and go to [http://localhost:3000](http://localhost:3000)

## Project Structure

- `src/` - React source code
- `public/` - Static files and HTML template

## Deployment

- Build for production:
  ```
  yarn build
  ```
  or
  ```
  npm run build
  ```
- Deploy the `build/` directory to your favorite static hosting service.
